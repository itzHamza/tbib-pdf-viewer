# TBiB PDF Viewer

An open-source, framework-agnostic PDF viewer with built-in annotation tools (freehand pen, highlight, rectangle, ellipse, text notes), published to npm.

## Packages

- **`@tbib-pdf-viewer/core`**: Framework-agnostic PDF rendering and annotation engine powered by PDF.js, `perfect-freehand`, and `pdf-lib`.
- **`@tbib-pdf-viewer/react`**: React component wrapper (`<PdfViewer>`, `<PdfToolbar>`).
- **`demo`**: Interactive demonstration showcase.
